## Phase 1 scope

1. Add a lazy-loaded, versioned MiewID-msv3 adapter using the publisher's preprocessing and frozen pretrained weights.
2. Add a global-model selector to the CzechLynx runner. Retain MegaDescriptor as the default and keep its compatible vector caches reusable.
3. Bind MiewID caches and threshold contracts to weights, model code/revision, transforms and input mode; reject incompatible checkpoint options.
4. Identify the chosen model in reports. Compare the new global-only predictions with the existing segmented baseline, checking input IDs and candidate coverage.
5. Add focused mocked regressions for model loading, preprocessing, extraction/cache behavior and CLI integration. Do not execute them automatically.
6. Document exact test/benchmark commands and expected output paths; update AGENTS.md with the actual new behavior.

No fine-tuning, score-calibration fitting changes or clustering algorithm changes are part of phase 1. No accuracy improvement is assumed in advance.
