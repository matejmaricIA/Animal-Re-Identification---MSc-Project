\chapter{Population Size Estimation}
\label{chap:population_counting}

This chapter describes the population size estimation component of the thesis. The goal is to estimate the number of unique individuals in a large image collection using the re-identification methods introduced in previous chapters while avoiding exhaustive pairwise comparison between all images.

\section{Introduction}

While individual animal re-identification provides the foundation for wildlife monitoring, the ultimate goal in many conservation and ecological applications is estimating population sizes. Traditional clustering approaches for population estimation often produce inaccurate results when applied to re-identification systems, particularly when the underlying pairwise similarities are noisy or unreliable~\cite{perez2024humanintheloopvisualreidpopulation}.

Perez et al.\cite{perez2024humanintheloopvisualreidpopulation} proposed a statistically focused alternative: \emph{Human-in-the-Loop Nested Importance Sampling} (HITL-NIS). Instead of attempting to fully cluster the dataset, the method estimates the cluster count directly by adaptively sampling a small number of image pair for vetting by an "oracle" (a human annotator that decies wheter a pair of images is of a same individual). For the purposes of their research and for the purposes of this thesis as well, human annotation was simulated by just taking the GT values from the publicly available datasets on which this was tested. Since the original paper didn't address the very real concern of human error during annotation, in this thesis I introduced a simulated variable of \emph{human labeling error} to test how it affects the estimator. The results of this analysis are presented in the next chapter, in this chapter I'll mostly focus on the theoretical background and implementation. 

\section{Theoretical Foundation}
\label{sec:theoretical_foundation}

\subsection{Population Size as Connected Components}

The population estimation problem can be formulated as counting connected components in a graph where vertices represent images and edges exist between images of the same individual. Formally, given a graph $G = (V, E)$ where vertices correspond to images and edges represent same-individual relationships, the number of clusters $K$ equals the number of connected components:

\begin{equation}
K = \text{CC}(G) = \sum_{u=1}^{n} \frac{1}{1 + d(u)}
\label{eq:connected_components}
\end{equation}

where $d(u)$ is the degree of vertex $u$ (i.e., the number of edges connected to $u$)~\cite{perez2024humanintheloopvisualreidpopulation}.

This elegant formulation arises from the observation that the graph $G$ consists of a collection of cliques, where each clique represents images of the same individual. The clique containing vertex $u$ has size $1 + d(u)$, and the total contribution of all vertices in this clique is $(1 + d(u)) \times \frac{1}{1 + d(u)} = 1$. Thus, each clique contributes exactly 1 to the sum, yielding the total number of connected components.

This formulation provides the foundation for statistical estimation: instead of computing all pairwise similarities explicitly, we can sample vertices and estimate their degrees, then use importance sampling to obtain an unbiased estimate of the population size.


\subsection{Two-Stage Estimation: Nested Monte Carlo and Nested Importance Sampling}
\label{sec:nis_theory}

The most direct Monte Carlo approach samples vertices uniformly:

\begin{equation}
\mathrm{CC}(G) = n\, \mathbb{E}_{u\sim \mathrm{Unif}(\{1,\dots,n\})}\left[\frac{1}{1+d(u)}\right].
\label{eq:cc_uniform_expectation}
\end{equation}

For a sampled vertex \(u\), its degree can be estimated by sampling candidate neighbors \(v\) the annotator whether an edge exists (are they the same individual in this case). Nested Monte Carlo (Nested-MC) does this with uniform neighbor sampling. Nested importance sampling (NIS) replaces uniform sampling with proposal distributions designed to reduce variance. The paper suggests an outer proposal \(Q\) that oversamples low-degree vertices and an inner proposal \(q\) that oversamples likely neighbors\cite{perez2024humanintheloopvisualreidpopulation}.

In it's general form, NIS estimator can be written like:
\begin{equation}
\widehat{\mathrm{CC}}_{\mathrm{NIS}}(G)=
\frac{1}{N}\sum_{i=1}^{N}
\left(
\frac{1}{Q(u_i)}\cdot
\frac{1}{1+\widehat{d}(u_i)}
\right),
\qquad u_i\sim Q(u).
\label{eq:nis_estimator}
\end{equation}

The degree estimator for a sampled vertex \(u\) uses importance weighting over neighbors:

\begin{equation}
\widehat{d}(u)=\frac{1}{M}\sum_{j=1}^{M}\frac{s(u,v_j)}{q_u(v_j)},
\qquad v_j\sim q_u(v),
\label{eq:degree_estimator}
\end{equation}


where \(s(u,v)\in\{0,1\}\) is the \emph{true} edge indicator.
 In HITL settings, \(s(u,v)\) is revealed by a human annotater and in this thesis it is 
 simulated from ground-truth values during experiments.

\section{HITL-NIS Implementation}
\label{sec:counting_implementation}

This section describes how population counting was implemented in this thesis and how it differs from the description in the original paper.

\subsection{Graph and Annotator Abstraction}
The counting pipeline represents the dataset by a list of image identifier \(\{id_i\}_{i=1}^{n}\). The graph \(G\) is never constructed explicitly, instead the algorithm queries an "annotator" function \(\mathcal{O}(id_u,id_v)\in\{0,1\}\) that returns whether two images belong to the same individual. As mentioned before, in the experiments for this thesis, \(\mathcal{O}\) is simulated using ground-truth identity labels.

\subsection{Cheap Proposal Signals: Global Embeddings and Fisher Vectors}
\label{sec:counting_signals}

Human annotation is "expensive" since it requiers a human in real development, so the method relies on cheap embedding signals to prioritize which pairs to query. As with classification, two base signals are supported.

\begin{itemize}
    \item \textbf{Global embedding similarity}: a single global feature vector is extracted per image (MD) and after L2 normalization cosine similarity is computed
    \item \textbf{FV similarity}: local descriptors are aggregated into FVs as described in Chapter\ref{sec:feature_aggregation} and again after L2 normalization, cosine similarity is computed
\end{itemize}

These signals are used \emph{only} for proposal distributions, the estimator ultimately depends on annotator verified edge indicators.

\subsection{Calibrating Scores to Probabilities for Sampling}
\label{sec:counting_calibration}
Raw cosine similarities are not calibrated and aren't comparable across signals. To obtain a proposal distribution that is closer to the ideal \(q_u(v)\propto s(u,v)\), the implementation support per signal calibration \(s_{\text{raw}}(u,v)\mapsto \widehat{p}(\text{same}\mid s_{\text{raw}})\) using monotone calibrators (isotonic regression, optionally with PCHIP interpolation for tie handling). Calibration pair are constructed from GT identities (this, ofcourse, means that it increases the human effort needed to label the calibration pairs, but only by about 1000-2000 pairs). 

To better match the distribution of pairs encountered during counting, negative calibration pairs are samples as hard negatives from a shortlist of high-similarity candidates, rather than uniformly at random. This is important because the decision boundary between ``same'' and ``different'' is most important among the near neighbors where the model is uncertain. 

At runtime, calibrated probabilities from the available signals are fused by averaging:

\begin{equation}
\widehat{p}_{\text{base}}(u,v)=\frac{1}{S}\sum_{m=1}^{S}\widehat{p}_m(u,v),
\label{eq:base_fused_probability}
\end{equation}

where \(S\in\{1,2\}\) depending on whether global embeddings and/or Fisher vectors are enabled.

\subsection{Outer Sampling Choice}

The original paper proposes an importance-weighted outer distribution \(Q(u)\propto 1/(1+\widehat{d}(u))\), 
where \(\widehat{d}(u)\) is estimated from approximate similarities~\cite{perez2024humanintheloopvisualreidpopulation}. 
This can reduce estimator variance by oversampling low-degree vertices that contribute more to \(\mathrm{CC}(G)\).

In this thesis, the outer sampling is set to \textbf{uniform} \(Q(u)=1/n\). The motivation is that constructing a reliable approximation to \(Q(u)\) would require 
estimating \(\sum_{v\neq u}\widehat{s}(u,v)\) for \emph{all} \(u\), which can approach \(O(n^2)\) computation/memory. By keeping \(Q\) uniform, the method retains the same ubiased estimator structure while focusing variance reduction on the inner neighbor proposal \(q\) which delivers the main savings in human effort. 

\subsection{Complexity and Diagnostics}

The total human query budget is \(N\times M\) (plus optional confirmation votes; see Section~\ref{sec:labeling_error}). For each run, the implementation reports:
the estimate \(\widehat{K}\) and a 95\% confidence interval. 

\section{Human Labeling Error}
\label{sec:labeling_error}

HITL-NIS assumes that a human annotator correctly labels each of the presented pairs. It's self evident that in practice this is a very wrong assumption. Human judgments will always be imperfect, especially for visually similar individuals and if the annotator is someone that's generally not very familiar with the animal species in question. This is not just a small issue, this directly violates the clique-graph assumptio behind equation\ref{eq:connected_components} because it introduces wrong edges. This is very harmful. Pairwise comparisons in a large dataset are dominated by non-matches, this means that even a small FP rate (incorrect labeling) can introduce made up edges that inflate \(\widehat{d}(u)\). Since the estimator uses \(1/(1+\widehat{d}(u))\), such errors can drastically decrease the estimated count (bias the population estimate downwad by effectively merging identities). This bias is not captured by confidence intervals since that accounts only for Monte Carlo sampling variance. This was not at all addresse in the original paper and I'll now discuss how I attempted to address it.  

\subsection{Explicit Noise Modeling}
\label{sec:error_sweeps}

To quantify the robustness of the method, I simulated a human error parameter by exposing the system to a paramter that introduces a random error in ranges from 2\% to 30\%. As expected, without any method to address this, the results of counting become completely unreliable at a 2\% error rate already. These result are reported in the next chapter. 

\subsection{Confirmation by Repeated Voting}
\label{sec:confirmation_votes}

False positives are more damaging than false negatives for cluster counting. To reduce false positives while limiting extrac human annotation cost, a following confirmation strategy was implemented:

\begin{quote}
    If the first human vote is ``different'', accept it immediately. If the first vote is ``same'', re-query teh \emph{same pair} and accept ``same'' only if it is returned \(K\) times consecutively.
\end{quote}

This method adds cost only for candidate matches (which are relatively rare), while reducing the probability that a single mistaken ``same'' response merges identities wrongly. The trade-off between robustness and additional human annotator calls is evaluated in the next chapter. 

\section{Parameter Configuration}
\label{sec:counting_parameters}

The implementation exposes parameters that control estimator variance, query budget, and robustness:

\begin{itemize}
    \item \textbf{\(N\)}: number of sampled outer-loop vertices
    \item \textbf{\(M\)}: number of sampled neighbors per vertex

    \item \textbf{Simulated label error}: human mistake probability \(p\).
    \item \textbf{Positive confirmation}: number of consecutive ``same''
     votes required to accept a match.
\end{itemize}

Increasing \(N\) and \(M\) reduces estimator variance but increases human annotator calls. Increasing the 
confirmation parameter improves robustness to false positives but also increases human annotator calls.
